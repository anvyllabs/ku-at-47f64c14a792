## Part A · Blank template (Lecture B · Template 5)

```markdown
USER TEST · five lines Tester: T__ (a code, no names)
1 Task: “Please ________.”
2 Watch for: pauses · wrong clicks · words said aloud
3 My rule: Stay quiet. Do not explain the app.
4 Record: tester code · date · made-up/public data used · what they DID
5 After: biggest problem → fix → test again with new people
```

### Writing tips
1. About five users find most usability problems (Nielsen, 2000).
2. Codes (T1, T2), never names.
3. Write behaviour, not “I like it”.
4. Helping ends the test.
