How this was built

BUSS215-06·07 example: the team kept one folder as the source of truth. AGENTS.md (auto-read) sets the rules; the Core 5 files hold the map, why, done-means, now-tasks, and history.

In Antigravity: first setup → AGENTS.md → P0–P5 (scope → requirements → create 6 files + 4 folders → verify → first task → continue next day in a new chat). Each work day: Start session (read 00_HOME → 03_TASKS → latest 04_WORKLOG entry) → work (check the diff before saving) → End session (log unfinished items and why).

Big choices are short ADRs in decisions/. Tests live in evidence/. Agents draft; humans approve scope and anything shared.
